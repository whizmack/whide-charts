# TradingView desktop reference

These ten screenshots were supplied by the user on 2026-10-22. They are the
canonical visual reference for the Whide Charts OpenCharts workspace. Before
changing a referenced area, inspect its screenshot and preserve the compact
desktop composition as closely as the app allows.

Use the screenshots to guide layout, control placement, menu structure,
settings, and density. Market values, dates, candle spacing, and browser zoom
are incidental screenshot content; do not use them as literal product data or
as a command to change chart zoom. Keep the original reference images intact.
