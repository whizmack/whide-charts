# Replay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lokální historický replay Binance USD-M s pravdivými partial bary, kreslením, indikátory a uloženými sessions.
**Architecture:** FastAPI poskytuje bezpečný prefix agregovaný z Parquet 1m dat. React drží společné asOf, Vela dostává pouze odhalené bary. SQLite ukládá sessions a katalog importů.
**Tech Stack:** Python 3.12, FastAPI, PyArrow/Pandas, SQLite, React, TypeScript, Vite, Vela 0.8.4.
**Spec:** `docs/2026-10-14-architecture-proposal.md`

## Global Constraints
- Jen Binance USD-M perpetual BTCUSDT, ETHUSDT, SOLUSDT; žádný live stream ani objednávky.
- 1m, 5m, 15m, 1h, 4h. UTC epoch ms. Přepnutí timeframe nemění asOf.
- Žádné finální OHLC vyšší svíčky, pokud ještě není dokončená; nikdy fallback na budoucnost.
- Volume, SMA, EMA, RSI, MACD a Bollinger Bands; existující nástroje Vela.
- SQLite a Parquet lokálně, bez placených služeb; viditelná atribuce Vela.
- Journal a quant nejsou součástí tohoto plánu.
- UI/UX: dominantní graf, střídmá tmavá paleta, nízká míra animací, kompaktní ovládání podle TradingView. Použít design-taste-frontend, better-ui, better-layout, better-accessibility a better-writing; userův pracovní graf má přednost před marketingovými výchozími styly skillů.
- Ověřit layout na laptopu i úzkém panelu, čitelnost tabulárních čísel, klávesnici, focus, popisky a loading/empty/error stavy.

## Review Focus
- Chybějící minuta a mezera mezi archivy: render se bezpečně zastaví, žádná syntetická svíčka (Task 1/2).
- Opoždělé odpovědi po přepnutí: nesmí přepsat nový timeframe a asOf (Task 3).
