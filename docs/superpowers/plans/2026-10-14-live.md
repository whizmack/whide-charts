# Live / Replay implementation plan

Goal: Add public Binance USD-M live candles to the existing terminal without contaminating replay.

Architecture: A separate in-memory LiveFeed owns a rolling 1,000-candle window. It connects to the documented market WebSocket endpoint and hydrates on every connection through a read-only, allowlisted REST proxy. Replay retains immutable local data and its independent clock. The chart instance is replaced on mode changes, retaining separate drawings and viewports and shared appearance.

Tech stack: Existing React/TypeScript/Vela, browser WebSocket, FastAPI/httpx. No added packages or account access.
